# City Sim

A small city simulation game built with Python and Pygame.

The goal of this project is to create a simple grid-based city builder where the player can place buildings, manage basic resources, and watch the city develop over time.

## Features

* Grid-based building placement
* Roads and residential buildings
* Basic economy system
* Population tracking
* Building costs and income
* Simple city simulation
* Demolition tool
* Save and load support

## Technologies

* Python
* Pygame

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd city-sim
```

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```

## Controls

* **Left Click** — Place selected building
* **Right Click** — Remove a building
* **ESC** — Exit the game
